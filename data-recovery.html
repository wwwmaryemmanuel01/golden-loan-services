    Environment Variable Names
    Names and requirements only — no value is ever shown or backed up
    values never exported
    Secret values live in the hosting provider's encrypted store. Only the names and their purpose are documented and backed up. A service-role key must never appear in the browser bundle, a backup export or a repository.
    Version Matrix
    The application, schema and dependency versions tied to each recovery point
    —
    Hosting requirements
    A source-code backup is not a database backup. The repository gives back the application, not the customers' records. Both are needed, in that order: restore the code, then the data — never one as a substitute for the other.

    Restore to Factory Settings — Safe Reset Modes

    Four separated modes with their own permission and confirmation. Each one states exactly what it changes and what it leaves alone, before anything runs

    —
    A factory reset is never a fix for a login, a layout or a failed deployment. Mode A and Mode B touch no financial record at all. Mode C redeploys code and keeps the database. Mode D is a disaster-recovery or decommissioning procedure with its own approvals — it is not offered here as a button, and it is disabled until a separate security review signs it off.
